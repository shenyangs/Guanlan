01 / Signal

Not search. Source intelligence.

Guanlan turns fragmented public web traces into provenance-aware material an agent can judge, cite, and continue from.

Provenance Who said it, where, and through which platform context.
Boundary What is official, what is media, what is only public discussion.
Packet Evidence arrives already shaped for downstream agent reasoning.
02 / Studio

Every query becomes a route.

Different questions deserve different waterways: government notices, hotboards, ecommerce surfaces, developer communities, original pages.

Route

Scope and profile select source families before the agent starts reading.

Read

Pages are cleaned into compact, source-aware context with quality notes.

Research

Source mix, freshness guardrails, and advisor notes make the packet useful.

03 / Run

One command. Many signals.

guanlan research "国产 AI 应用 出海" --profile china --limit 80 --advisor
China-aware Profiles and scopes mirror Chinese web structure.
Agent-ready Markdown, JSON, MCP, and local workflow outputs.
Traceable Quality signals tell you when evidence is thin.
04 / Install

Install the river into your agent.

Use one clean install path, then smoke test before wiring it into your agent.

uv 
uv tool install --force --upgrade guanlan
guanlan version
guanlan doctor --install-check
Homebrew 
brew update
brew reinstall shenyangs/tap/guanlan
guanlan hotnews today --limit 80
