02 / Run

Designed for the agent’s next step.

Every response is shaped so another agent, MCP client, or local model can continue without guessing what the evidence means.

guanlan compare "产品A" "产品B" --focus "价格 口碑 风险" --limit 80 --format context
China-aware Profiles and scopes mirror Chinese web structure.
Agent-ready Markdown, JSON, MCP, and workflow outputs.
Traceable Quality signals explain when evidence is thin.
Read-only Public search and reading before authenticated actions.
