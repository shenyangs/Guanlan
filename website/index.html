The Shift

不要把观澜讲成搜索工具，要把它放进 Agent 的工作流位置里。

Agent 真正缺的不是更多链接，而是一层能持续判断“去哪找、谁在说、能不能信、怎么复用”的信息结构。

观澜把中文互联网里的官方、媒体、社区、热榜、网页正文和本地 archive 组织成 Agent 能继续工作的证据包。

Before / After

从零散搜索结果，到持续研究上下文。

没有观澜

Agent 只能拿零散搜索结果工作。

  • ×不知道该去哪搜
  • ×分不清官方、媒体、社区和营销内容
  • ×容易把网页片段当事实
  • ×查过的资料用完就丢
接入观澜后

Agent 开始围绕证据包持续研究。

  • ✓自动路由中文信源
  • ✓阅读网页并判断正文质量
  • ✓保留来源身份和证据角色
  • ✓把资料沉淀到 archive / Wiki / RAG

What Agent Gets

不是功能堆叠，是一层可调用的信息判断力。

01

信源路由

根据问题把 Agent 带到官方、垂类、社区、热榜或开发者信源。

02

语境识别

保留来源身份、平台语境、证据角色和结果边界。

03

网页阅读

读取正文、判断质量，并在弱页面时给出诊断和下一步路径。

04

资料复用

把研究材料沉淀为 archive、Wiki、RAG 或 Agent 上下文。

Three Steps

三步接入，让 Agent 开始围绕中文证据工作。

1

安装观澜 CLI

uv tool install --force --upgrade guanlan
2

交给 Agent 使用

guanlan mcp config --client codex
3

开始研究

guanlan research "中文问题" --advisor
