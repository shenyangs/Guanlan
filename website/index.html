The Thesis

Agent 真正缺的不是更多链接，而是能持续判断信息的那一层。

中文互联网不是一个平面网页库。它由官方口径、垂直媒体、平台社区、热榜流、动态页面和大量营销内容共同构成。观澜把这些材料先变成结构，再交给 Agent 使用。

Research Layer

从搜索请求到证据包，观澜只做一件事：让 Agent 更会研究。

01

先判断去哪找

把问题路由到官方、垂直、社区、财经、学术、娱乐、开发者或热榜信源。

02

再判断谁在说

保留来源身份、平台语境、证据角色、时间线和风险提示，让链接不再只是链接。

03

最后沉淀成资料

把研究过程留在 archive、Wiki、RAG 或 Agent 上下文里，下一次可以继续工作。

Before / After

普通搜索结束于网页。观澜开始于证据结构。

没有观澜

Agent 拿到一堆零散结果。

不知道该信谁，不知道页面正文质量，也很难把一次搜索变成下一次可复用的研究上下文。

接入观澜后

Agent 拿到可继续工作的证据包。

知道去哪找、谁在说、证据边界在哪，以及这些材料应该如何进入 archive / Wiki / RAG。

Install

三步接入。让 Agent 开始认真处理中文互联网。

guanlan setup
  1. 1

    安装观澜 CLI

    uv tool install --force --upgrade --refresh --default-index https://pypi.org/simple guanlan
  2. 2

    交给 Agent 使用

    guanlan mcp config --client codex
  3. 3

    开始研究

    guanlan research "中文问题" --advisor
